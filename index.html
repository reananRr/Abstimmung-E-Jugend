⚽ E-Jugend – Turnierauswahl

Geheime Trainerabstimmung · 19 Spieler · 8 Stimmen pro Trainer

1. Spielerliste festlegen

Vor dem Versand die 19 Namen eintragen und „Liste übernehmen“ drücken. Danach dieselbe Datei an alle Trainer senden. Die Abstimmungscodes sind nur mit derselben Spielerliste gültig.

2. Acht Spieler wählen

0 von 8 gewählt

Nur den Code an die Person schicken, die die Stimmen auswertet. Deine Auswahl wird nicht automatisch übertragen.

3. Auswertung (nur für die organisierende Person)

Hier die Codes aller Trainer einfügen, jeweils einen Code pro Zeile. Doppelte Codes werden nicht mehrfach gezählt. Ein Trainer könnte technisch mehrere unterschiedliche Codes erzeugen; bitte nur einen Code pro Trainer akzeptieren.

Ergebnisbericht für alle Trainer

Datenschutz: Diese Datei sendet keine Daten an einen Server. Namen und Stimmen bleiben auf den jeweiligen Geräten bzw. in den von euch versendeten WhatsApp-Nachrichten.
